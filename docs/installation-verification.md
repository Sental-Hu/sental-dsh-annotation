# 0.1.17 安装验证

验证日期：2026-09-14。功能代码提交：4825671。

## 环境

Windows、Node.js 24.14.0、pnpm 11.19.0、Edge，以及 DSH 0.1.5-rc.1 本地构建（183f08e）。独立 DSH_HOME 和测试会话；模型使用本机确定性测试服务。

## 已验证

- 从 GitHub 私有仓库重新克隆，使用锁文件安装依赖。
- ESLint、TypeScript 检查通过；23 个测试文件、155 个用例通过。
- 构建与打包通过，生成的 tgz 通过 DSH plugin 命令成功安装。
- 真实 Edge 页面可划选回答、打开批注弹窗，并显示保存和发送按钮。
- 点击发送：批注原文和评论进入会话，模型收到一次提交；输入框既有草稿未进入模型请求，且原样保留。
- 发送成功后，记录出现在输入框上方的历史批注列表。
- 刷新后，已发送历史和输入框草稿仍可恢复。
- 打开批注详情后点击外部，详情收起。
- 点击保存：新批注加入待发送列表和输入引用，未自动调用模型。

## 版本修复

0.1.16 的直接发送错误地要求客户端请求编号与服务端生成的批次编号一致，可能导致只保存而不发送。0.1.17 保留服务端生成身份的规则，通过准备响应中的新建状态区分提交方和复用方。跨前后端回归用例覆盖单页面及两个页面并发，保证同一批注只提交一次。

## 验证范围

本次没有在 macOS、Linux 或 iOS 真机执行完整操作，也没有测试真实模型供应商。结果说明上述 Windows/Edge/DSH 构建中的安装和交互链路可用，不代表所有 DSH 预发布版本均已验收。
